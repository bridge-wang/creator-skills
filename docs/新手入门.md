# creator-tools 新手入门

creator-tools 提供 3 个独立 Skill。先找到手里的素材和希望得到的结果，再按对应入口开始。返回 [仓库首页](../README.md)。

## Skill 全目录

| Skill | 适用时机 | 必需输入 | 主要交付 |
| --- | --- | --- | --- |
| [bri-video-srt](../skills/bri-video-srt/SKILL.md) | 原始口播粗剪；精剪后生成字幕；已有字幕校准 | 视频/音频路径及当前阶段，或 SRT 文件 | 粗剪视频与审核材料，或最终 SRT |
| [bri-cover-generate](../skills/bri-cover-generate/SKILL.md) | 从无字幕视频制作多平台封面 | 无字幕视频路径、封面文字 | 3 张候选；选定后的四比例 PNG |
| [bri-chinese-typeset](../skills/bri-chinese-typeset/SKILL.md) | 中文或中英混排文稿需要统一排版 | 粘贴文字，或可读取的文本文件 | 保留措辞的排版全文 |

这些 Skill 不负责平台发布。制作结果是否上传，由你另行决定。

## 安装与更新

推荐通过 skills CLI 安装：

```bash
npx -y skills add bridge-wang/creator-skills -g --all
```

只安装一个 Skill：

```bash
npx -y skills add bridge-wang/creator-skills -g --skill bri-chinese-typeset -y
```

安装到当前项目的 Codex：

```bash
npx -y skills add bridge-wang/creator-skills --skill bri-chinese-typeset --agent codex -y --copy
```

后两条命令中的 Skill 名可换成目录中的另一个名称。安装后若当前会话没有识别到新 Skill，可新开一次对话再调用。

Claude Code 插件市场：

```bash
claude plugin marketplace add bridge-wang/creator-skills
claude plugin install bri-video-srt@creator-tools
claude plugin install bri-cover-generate@creator-tools
claude plugin install bri-chinese-typeset@creator-tools
```

按需执行对应的插件安装命令。插件方式安装后，从 Claude Code 命令列表选择对应能力；其显示入口可能包含插件命名空间。

更新插件：

```bash
claude plugin marketplace update creator-tools
claude plugin update bri-video-srt@creator-tools
claude plugin update bri-cover-generate@creator-tools
claude plugin update bri-chinese-typeset@creator-tools
```

也可以让 Agent 更新仓库中相应 Skill。更新前先比较本地修改，保留你修改过的术语表、保护短语和任务文件；原始媒体与交付文件继续放在工作目录。

## 环境准备

| 能力 | 所需环境 |
| --- | --- |
| 文字排版 | 支持 Skill 的 Agent；正常使用不需要额外运行库 |
| 视频字幕 | Python 3、FFmpeg / FFprobe、whisper-cli、已有的 large-v3-turbo ggml 模型 |
| 视频粗剪 | 字幕环境，加 auto-editor |
| 封面生成 | Python 3.10+、Pillow、FFmpeg / FFprobe；字体已内置，不需要 Whisper |

字幕使用 `WHISPER_MODEL` 指定的已有模型，默认查找 `~/Models/whisper/ggml-large-v3-turbo.bin`。缺失或损坏时先说明问题，不静默下载另一份。不同平台的编码器和工具安装方式可能不同；先自检再执行。

在对应 Skill 的根目录运行自检，或让 Agent 代为定位：

```bash
# bri-video-srt 根目录
bash scripts/check_setup.sh

# bri-cover-generate 根目录
python3 scripts/cover_pipeline.py doctor
```

自检用于发现缺少的工具，不会自动安装工具或下载模型。

## 原始视频先粗剪

给出原片路径并明确说“粗剪”。Skill 会先查看声音与画面，识别气口、候选重复口播和需要保留的屏幕操作，再生成粗剪版本。

你会得到粗剪视频、同步审核字幕和剪辑记录。先试听切点、查看字幕与操作画面，再进入剪辑软件做人工精剪。粗剪不是自动完成全部剪辑；尤其应检查句首、低声短句、关键停顿和演示步骤。

## 时间轴锁定后生成最终字幕

把人工精剪后导出的成片交给 Agent，并明确说明时间轴已经锁定。优先提供与画面同步的成片音轨。流程包括重新转写、术语与语义校准、音频重锚定及中文排版。

默认交付独立 `.srt`，不烧录字幕。导入剪辑软件后，检查前段、中段、结尾以及关键专名。只有一份现成 SRT、没有同时间轴音频时，可以做文字校准，无法凭空核实音频时间。

## 先选封面，再出四比例

提供无硬字幕视频与标题。标题通常两行，也支持 1～4 行；`·` 默认表示换行，不印在封面上。Agent 会先抽取真实画面并展示 3 张 3:4 候选。

回复“选 A”“选 B”或“选 C”，再生成四张封面：

| 比例 | 尺寸 |
| --- | --- |
| 3:4 | 1440 × 1920 |
| 9:16 | 1080 × 1920 |
| 16:9 | 1920 × 1080 |
| 4:3 | 1440 × 1080 |

以上尺寸以 Skill 当前默认配置为准，执行前应读取实际配置。默认样式为 65% 黑色遮罩与白色思源宋体 Bold。每个比例从选定的原始帧重新裁切和排字，不裁切已经排好字的成品图。

竖版素材制作横封面默认使用同帧左右重复拼接，不镜像人物。缺少无字幕素材、字体校验失败或特殊色彩输入无法明确处理时，会先说明缺项。选定帧、参数、结果清单和字体许可随任务保留，便于复现。

## 保留内容的中文排版

直接提供文字：

```text
/bri-chinese-typeset 请排版：用检索+生成整理文档，预计4-6分钟。
```

输出：用检索 + 生成整理文档，预计 4～6 分钟。

规则包括中英文与数字间距、单位例外、中文标点、全半角和已知专名大小写。另有两项默认约定：组合加号两侧留空格，范围短横杠改为全角波浪线。英文连字符、日期、负号、公式、代码和链接按用途保护。

默认只输出全文，不润色、不纠正用词；只有要求保存时才写文件。本次任务的明确约定优先于默认规则。

## 资料和结果放在哪里

规则与脚本随各自的 Skill 分发。粗剪审核材料放在媒体旁的审核目录；封面目录通过 `job.json` 和成品清单保存参数。你提供的原始媒体、参考图和任务记录不应写进公开 Skill 资源。

本地 Whisper 执行语音转录；抽帧和封面渲染也在本地。Agent 阅读文字或查看画面时，内容如何进入模型上下文由客户端及模型配置决定。
