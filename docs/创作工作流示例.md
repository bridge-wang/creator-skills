## 1．原始口播粗剪

**准备：** 一条未剪的口播视频；若包含屏幕操作，说明哪些演示步骤必须保留。

**发给 Agent：**

```text
/bri-video-srt
请粗剪这条原始口播：/path/to/原始口播.mp4
视频中有软件操作，保留必要的输入、切页和结果展示。
先交付粗剪视频与审核字幕，我会继续人工精剪。
```

**你会得到：** 粗剪视频、同步审核 SRT 与剪辑记录。

**怎么检查：** 试听剪切前后是否完整；检查重说是否正确删除、句首有没有被切掉、必要操作是否仍能看懂。确认后进入剪辑软件做人工精剪。

## 2．精剪成片生成字幕

**准备：** 已经人工精剪、时间轴不再变化的成片。给出希望固定书写的专名。

**发给 Agent：**

```text
/bri-video-srt
这条视频已经人工精剪并锁定时间轴：/path/to/精剪成片.mp4
请生成独立的最终 SRT，不烧录字幕。
专名统一写作 GitHub、Node.js。
```

**你会得到：** 校准、重锚定并排版的最终 SRT。

**怎么检查：** 导入剪辑软件，对照前段、中段、结尾的发言，检查专名、断句与时间。若重新剪了视频，应以新时间轴重新处理字幕。

## 3．已有 SRT 校准

**准备：** 一份现成字幕。如果希望核对时间，附上同一时间轴的音频或视频。

**发给 Agent：**

```text
/bri-video-srt
请校准这份字幕的专名、文字和断句：/path/to/现有字幕.srt
目前没有对应音频，请保留已有时间轴，不推测新的音频锚点。
```

**你会得到：** 校准后的 SRT。

**怎么检查：** 核对专名、语义、字幕顺序和时长。没有音频时，文字校准不能证明时间戳准确。

## 4．无字幕视频生成封面

**准备：** 无硬字幕的视频，以及希望出现在封面上的文字。

**发给 Agent：**

```text
/bri-cover-generate
视频：/path/to/无字幕视频.mp4
封面文字：复杂的事情·从简单处开始
先展示三张候选。
```

**继续对话：** 看完候选后回复“选 B”，再获得四比例成品。`·` 表示换行；希望保留这个符号时需明确说明。

**你会得到：** 三张候选，以及选定后的 3:4、9:16、16:9、4:3 PNG 和总览。

**怎么检查：** 人脸是否清晰、标题是否正确、额头和下巴是否被误裁、各比例边距是否合适。默认采用 65% 黑色遮罩与白色思源宋体 Bold。

## 5．中英混排文稿整理

**准备：** 一段需要统一排版、但不希望改写措辞的文字。

**发给 Agent：**

```text
/bri-chinese-typeset
请只排版，不改写：这份API说明共12页，采用检索+生成方式整理，预计4-6分钟。
```

**你会得到：** 这份 API 说明共 12 页，采用检索 + 生成方式整理，预计 4～6 分钟。

**怎么检查：** 内容和数字没有变化，中英文间距统一；组合加号两侧有空格，范围使用波浪线。日期、型号、负号、代码和 URL 内部不应被误改。

## 使用时记住

只提供当前任务需要的素材。粗剪、最终字幕、封面和文字排版可以分开进行；先明确输入状态，再检查阶段结果。最终是否发布到平台，由你另行决定。
