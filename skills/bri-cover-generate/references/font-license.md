# 字体来源与许可

内置且唯一的渲染字体为 Adobe 官方 **Source Han Serif SC Bold v2.003**，中文名思源宋体。参考博主本人是否使用同一字体尚未获得公开确认；本 Skill 复用的是用户比较后选定的近似方案。

- 官方项目：[Adobe Fonts / Source Han Serif](https://github.com/adobe-fonts/source-han-serif)。
- 固定提交：`7889f11bf31170b5d092a083b357c8c8130f89e0`。
- [固定版本完整许可证](https://github.com/adobe-fonts/source-han-serif/blob/7889f11bf31170b5d092a083b357c8c8130f89e0/LICENSE.txt)。
- [OFL 官方 FAQ](https://openfontlicense.org/ofl-faq/) 的 1.1、1.1.1、1.1.2 说明设计作品及商业使用。
- 本地原文：[LICENSE.txt](../assets/fonts/LICENSE.txt)。下载 URL、日期与哈希：[provenance.json](../assets/fonts/provenance.json)。

字体采用 **SIL Open Font License 1.1**。许可允许使用字体制作商业封面、图片和视频标题，以及销售这些设计作品；生成的图片本身无需采用 OFL，也无需在封面上署名字体。不要将字体软件本身单独售卖。

再分发本 Skill、模板或字体文件时，保留原版权声明及完整许可证。修改字体文件或销售包含字体的软件包与销售封面图片是不同场景：字体衍生版本仍受 OFL 约束，并应遵守保留字体名称（Source）等条款。本 Skill 不修改字体文件。

渲染前脚本核对：字体与许可证 SHA-256、字族/字重和标题字符覆盖。任一失败时不退回系统字体。新增字形或改换字体时，需要先保存该字体官方来源与实际许可，再调整校验配置；“免费字体”描述不足以替代许可原文。

这些记录证明实际使用的字体文件及本任务用途的许可依据，不对参考图片里未知字体作授权推断。
