# 样式与取景依据

目标是接近用户对标的白色宋体封面：真实视频画面压暗，标题处于视觉中心，字形较厚但保留宋体横细竖粗的特点。参考截图经过平台缩放与压缩，无法据此唯一恢复原字体或精确遮罩比例；固定默认值来自实际对照后用户的明确选择。

## 第二套排版

参数真源：[assets/style.json](../assets/style.json)。

| 参数 | 默认值 |
| --- | --- |
| 字体 | Source Han Serif SC Bold，官方 v2.003 |
| 黑色遮罩不透明度 | 0.55 |
| 文字颜色 | 纯白 |
| 附加字距 | 字号 × 5/76 |
| 中文／拉丁字符边界额外间距 | 字号 × 0.1 |
| 行间空白 | 各行最大实际墨迹高度 × 0.5 |
| 标题中心 | 画面宽高各 50% |
| 3:4、9:16 标题最大宽／高占比 | 0.76 / 0.32 |
| 16:9 标题最大宽／高占比 | 0.56 / 0.44 |
| 4:3 标题最大宽／高占比 | 0.75 / 0.44 |

字号取满足宽高约束的最大整数，允许 48–400 px；按真实字形包围框而非字符数量平均分配。宽高限制与字数共同决定留白。短标题可用一行；过长标题先按语义分行，不缩小到无法识别。若用户明确要求特定字号，在任务副本 `style.variants[].font_size_px` 中设置并检查所有比例。

每次从原始帧加一次黑色遮罩，不对已压暗候选再叠一层。`55%` 是黑层不透明度，不是背景透明度。除裁切、等比缩放和遮罩外不调整色彩，保持真实画面。

## 四比例构图

优先让选帧在 3:4 与 16:9 中都成立。9:16 需要更窄的构图，重新裁原始画面并重新排字；4:3 同样从原始画面重排。不能认为直接裁成品必然安全。

竖版源帧做横图时，将同一帧等比裁成左右两个面板重复使用，不做镜像；默认横图裁切锚点 `(0.5, 0.15)` 偏向上部，减少人物额头被裁风险，但必须逐次查看。主体偏离中心、手势靠边或镜头变化时，不假定该值通用。横版源帧使用单画面，优先保留完整主体。

黑边探测对多个样本的近黑边缘进行一致性判断，只输出建议，不能区分所有真实深色背景。检查建议坐标后再传给 `candidates`。探测失败时保留全帧或经目视核验后手动指定；不要写死任何历史视频的裁切坐标。

## 完成证据

三张候选用同一标题与样式比较画面，候选标签和时间点放在总览外框，不进入正式封面。成品没有平台播放量、时长、关注按钮、截图圆角或 UI。视觉验收包括清晰度、表情差异、人物裁切、字形、两行视觉平衡和小尺寸可读性。
