# 样式与取景依据

目标是接近用户对标的白色宋体封面：真实视频画面压暗，标题处于视觉中心，字形较厚但保留宋体横细竖粗的特点。参考截图经过平台缩放与压缩，无法据此唯一恢复原字体或精确遮罩比例；固定默认值来自实际对照后用户的明确选择。

## 参考测量后的排版规则

参数真源：[assets/style.json](../assets/style.json)。

| 参数 | 默认值 |
| --- | --- |
| 字体 | Source Han Serif SC Bold，官方 v2.003 |
| 黑色遮罩不透明度 | 0.65 |
| 文字颜色 | 纯白 |
| 附加字距 | 字号 × 0.12，可在任务中从 0.10–0.13 校准 |
| 中文／拉丁字符边界额外间距 | 字号 × 0.1 |
| 行间空白 | 各行最大实际墨迹高度 × 0.5 |
| 标题中心 | 画面宽高各 50% |
| 3:4、9:16 标题最大宽占比 | 0.74，常见参考范围 0.70–0.75；六字长行可试 0.79 |
| 16:9／4:3 标题最大宽占比 | 0.56／0.75，保留各比例的横向布局约束 |
| 两行／三行／四行标题最大高占比 | 0.48／0.56／0.82；四行短词可在任务中试到 0.85 |
| 一行标题最大高占比 | 0.32，沿用的起点，本次无单行测量样本 |

字号取满足宽高约束的最大整数，自动模式从 48 px 起试，不再用 400 px 硬上限限制短标题。按实际字体渲染每行，得到字面宽 `w_i`、字面高 `h_i`，计算净空 `G = round(0.5 × max(h_i))` 和文字块高 `H = sum(h_i) + (N−1)×G`。同时检查 `max(w_i)` 与画布宽度、`H` 与画布高度；不要用字符串长度代替字面宽，也不要把行间净空误当成基线行高。

短词多行由总高度约束，长行由宽度约束，不要求所有标题占满宽高。`max_title_height_ratio_by_line_count` 是按行数取值的起点；variant 的 `max_title_height_ratio` 为 `null` 时采用该表，数值时优先使用显式覆盖。固定字号用任务副本 `style.variants[].font_size_px`，仍需通过宽高检查。混合英文／数字的字面高可能与汉字不同，应核对最终墨迹框。

### 测量依据和可用起点

2026 年 10 月参考截图中共有 12 张完整封面：两行 7 张、三行 4 张、四行 1 张。独立品牌顶栏、平台 UI 不计入主标题。原截图不能唯一恢复字体或编辑器字号，下面均为按字面高度拟合的 **思源宋体 Bold 等效参数**，画布为 **1440×1920**；不是原作者的精确软件设置。

| 主标题行数 | 最长行的样本长度 | 等效字号 | 行间净空 |
| --- | --- | --- | --- |
| 2 | 约 6 个汉字 | 170–180 px | 85–90 px |
| 2 | 约 4 个汉字 | 230–245 px | 约 120 px |
| 2 | 约 3 个汉字 | 约 320 px | 约 160 px |
| 2 | 2 字、含 AI 的特大字特例 | 约 405 px | 约 235 px |
| 3 | 约 5 个汉字 | 185–200 px | 95–100 px |
| 3 | 约 4 个汉字 | 约 235 px | 约 115 px |
| 3 | 约 3 个汉字 | 约 275 px | 约 135 px |
| 4 | 每行约 2 个汉字 | 约 305 px | 约 150 px |

长度只描述样本，英文和数字不按等宽汉字计数。参考中标题总高占比：两行 22%–48%、三行 38%–56%、四行 85.2%。因此不能把所有竖版标题总高固定为 32%。四行只有一个短词样本；更多字的四行、9:16 和横版参数属于按字形与画布推导的适配，必须看图，不能称为直接测量值。横版先沿用行数对应的相对高度，再结合取景和视觉密度调整。

12 张的「净空／最大字面高」中位数为 0.515；除两行 `AI / 剪辑` 的特大字特例约 0.61 外，其余在 0.495–0.529。默认保留 0.5，特例可在任务中调到约 0.6。用本字体按字高拟合后，纯中文附加字距的等效中位数为 0.122em，中间 50% 为 0.109–0.131em，因此默认用 0.12em。截图常规阈值复核的字面边界变化约 2 个原图像素；四行末行受平台渐变影响，不把测量值写成绝对精度。

表格用于选起点和视觉核对，不把某个标题的 310 px 等单次参数写成所有封面的默认字号。生成封面时的任务图和测量记录只在临时工作区使用，交付后删除，不打包进 Skill 或五图目录；用户另行要求的参考图分析按该分析任务交付。未指定分行时，过长标题可按语义分行；用户明确给定的标题和换行保持不变。

每次从原始帧加一次黑色遮罩，不对已压暗候选再叠一层。`65%` 是黑层不透明度，不是背景透明度。除裁切、等比缩放和遮罩外不调整色彩，保持真实画面。

## 四比例构图

优先让选帧在 3:4 与 16:9 中都成立。9:16 需要更窄的构图，重新裁原始画面并重新排字；4:3 同样从原始画面重排。不能认为直接裁成品必然安全。

竖版源帧做横图时，将同一帧等比裁成左右两个面板重复使用，不做镜像；默认横图裁切锚点 `(0.5, 0.15)` 偏向上部，减少人物额头被裁风险，但必须逐次查看。主体偏离中心、手势靠边或镜头变化时，不假定该值通用。横版源帧使用单画面，优先保留完整主体。

黑边探测对多个样本的近黑边缘进行一致性判断，只输出建议，不能区分所有真实深色背景。检查建议坐标后再传给 `candidates`。探测失败时保留全帧或经目视核验后手动指定；不要写死任何历史视频的裁切坐标。

## 完成证据

三张候选用同一标题与样式比较画面，候选标签和时间点放在总览外框，不进入正式封面。成品没有平台播放量、时长、关注按钮、截图圆角或 UI。视觉验收包括清晰度、表情差异、人物裁切、字形、两行视觉平衡和小尺寸可读性。
