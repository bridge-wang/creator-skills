# 工作流、复现与故障处理

## 问题契约

反复出现的问题：每条视频都要重新挑封面帧、统一宋体风格并适配多平台比例；人工调整难以稳定复现。

使用情境：用户已有无字幕视频和标题，希望先比较三张候选，再确定最终封面。

交付：三张 3:4 候选及总览；用户选择后交付四张 PNG 与总览；保留字体许可、原始选帧、裁切和排版参数。

完成证据：输出实际存在且尺寸正确，人工查看通过，文案一致，许可证校验通过，用户选择与最终原始帧一致。

近邻边界：不承担视频剪辑、转录、去字幕或静态图生成式扩图。

## 命令与状态

脚本：[cover_pipeline.py](../scripts/cover_pipeline.py)；排版模块：[render.py](../scripts/render.py)。

| 命令 | 输入 | 输出／状态 |
| --- | --- | --- |
| `doctor` | 已有运行环境 | 依赖及字体证据检查 |
| `prepare` | 视频、标题、新输出目录 | 抽样接触表、`job.json`，`prepared` |
| `sample` | 已有任务、时间点 | 加密抽样接触表，不改变选图状态 |
| `candidates` | 三个目视筛选后的时间点、可选裁切 | 三张候选、总览，`candidates_ready` |
| `finalize` | 当前候选的明确选择 | 四比例、总览、清单，`finalized` |
| `status` | `job.json` | 恢复参数、候选、选择、文件登记 |
| `cleanup` | 完成任务，可选 `--apply` | 列出／删除未改动的临时文件 |

目录结构由脚本生成，候选和成品按批次编号递增，不覆盖旧批次。清理保留历次总览作为审美依据，删除逐帧样本、候选单图和未选原始帧。默认不打包字体的重复副本：Skill 保留字体，任务目录保留许可证与来源；移动任务到其他电脑时，需要同时安装本 Skill。

`job.json` 保存源视频绝对路径、文件大小／修改时间、显示方向尺寸、时间点、原始帧哈希、标题、样式快照和文件登记。`manifest.json` 保存每个比例的实际字号、文字包围框、背景裁切、文件哈希和字体参数。固定 sRGB 配置文件避免每次编码产生带不同时间戳的 ICC；像素结果仍需相同 Pillow/FreeType/FFmpeg 环境才能保证完全一致。

## 常见情况

- **只有带字幕视频：** 查找并验证同源无字幕版本，找不到就请用户补充；不擦字。
- **只有一两帧可用：** 加密抽样；仍不足时如实展示可用数量并说明，不能把相同图伪装成三种候选。脚本要求三个不同时间点，需要确实可用后再运行。
- **标题不合适：** 保留文字，先调整语义分行；显式换行优先。超长或缺字只报告实际问题。
- **用户选了旧批次：** 找到对应时间点重新出图核对，不误用当前批次同名 A/B/C。
- **原始视频改变：** 抽帧会拒绝；创建新任务，不在旧参数上继续猜测。
- **已清理后想改选：** 新建候选批次，沿用已记录的时间和裁切，先目视核验再生成成品。
- **用户只改遮罩：** 在明确授权的新批次指定 `--opacity`，选帧不变。原图始终只叠加一次遮罩。
- **换机器：** 保留 `job.json`、选定 raw PNG、许可、清单；安装相同 Skill。若原视频路径变化，先验证文件和内容再更新路径、重新抽样；不要跳过完整性校验。
- **输出目录中有其他文件：** 清理完全忽略未登记文件；已登记文件被用户改过则跳过并记录，不强制删除。

## 制作依据

本 Skill 按用户指定的 [dbs-skill-maker](https://github.com/dontbesilent2025/dbskill/tree/8b8e33f1ecaed8cee606fe950c4426b525ead314/skills/dbs-skill-maker) 构建，使用其结构校验器与分级验证规则。本地开发评测按需保存在 `evals/results/`，发行包不包含私有样本、预期答案与本机运行记录。结构和真实行为测试不等于新素材盲测；安装验证也不能替代画面审查。
