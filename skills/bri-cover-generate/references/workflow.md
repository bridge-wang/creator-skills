# 工作状态与五图交付

## 交付契约

最终目录名固定为本地日期 `M月D号-封面`，例如 `10月6号-封面`。日期不补零，使用“号”和半角短横杠。目录直接包含以下五张图，无子目录、无说明或参数附件：

```text
10月6号-封面/
  封面-3x4.png
  封面-9x16.png
  封面-16x9.png
  封面-4x3.png
  总预览图.jpg
```

图的尺寸分别为 1440×1920、1080×1920、1920×1080、1440×1080；总预览图同时展示这四张图。渲染参数和字体规则见 [style-and-framing.md](style-and-framing.md)。用户明确修改交付要求时遵从其请求；不自行变更目录名、增添文件或保存隐藏备份。

## 工作区与命令

脚本：[cover_pipeline.py](../scripts/cover_pipeline.py)；排版模块：[render.py](../scripts/render.py)。

| 命令 | 行为 |
| --- | --- |
| `doctor` | 检查已有依赖和 Skill 中的字体、许可 |
| `prepare --video ... --title ... [--out ...]` | 在系统临时目录创建工作区，返回实际 `job.json` 路径；`--out` 是最终五图目录 |
| `sample --job ... --times ...` | 临时加密抽样 |
| `candidates --job ... --times ...` | 临时三张候选及总览，等待用户选择 |
| `finalize --job ... --pick A` | 从选定帧制作四比例图、总览和临时清单，供视觉验收 |
| `deliver --job ...` | 校验并导出五张图，然后删除整个工作区 |
| `deliver --job ... --dry-run` | 仅核对导出与清理范围，不写入或删除 |
| `status --job ...` | 仅在工作区尚未删除时恢复状态 |

`prepare` 默认把最终目录放在输入视频同级。若实际抽帧使用的是另一个子目录内的同源无字幕视频，用 `--out` 指向用户视频对应的交付位置。标题、样式、候选、raw 帧、`job.json`、`manifest.json`、旧批次和所有预览都只保留到交付完成。字体许可不复制到任务目录，保留在 Skill 本身。任务没有完成、正在等用户选图时，临时状态仍可继续使用。

`deliver` 验证四张 PNG 的比例、尺寸、完整性与校验值，以及 JPEG 总预览图。它先把五张图复制到目标父目录的临时位置，检查完成后改为正式目录，再删除所有工作文件。最终目录不包含 `final-001` 等批次层级，不保留选定 raw 帧、接触表、JSON、Markdown、日志、许可证副本或压缩包。不要在旁边另建归档规避删除要求。本次 Skill 修改和排错使用的临时开发副本也应在完成后清除，不能留在用户媒体目录。

清理只接受工作清单登记且未被改动的文件，外加任务本身的 `job.json` 和系统 `.DS_Store`；有未登记、被修改或符号链接文件时停止清理并核对归属。原视频必须位于工作区之外。不要删除用户原视频、参考图、用户另外要求的分析交付物或其他无关文件。

## 继续、迁移与修订

- **已有明确选择：** 直接沿用，不要求用户重复选图。
- **旧任务迁移：** 在已验证的旧 `job.json` 上执行 `deliver --out '/实际路径/M月D号-封面'`。最终目录必须与旧工作目录分开；导出成功后旧目录整体删除。`cleanup` 为兼容旧调用保留，默认等同 dry run，`--apply` 等同完整交付与清理，不再保留 raw 或元数据。
- **重做同一份成品：** 用户已明确要求重做或覆盖该目录时，可给 `prepare` 或 `deliver` 加 `--replace`。只替换恰好包含上述五个普通文件的目录；存在其他文件则先核对归属。同日不同视频使用各自的项目父目录，不能覆盖另一个视频的成品，也不能随意给标准目录追加数字后缀。
- **交付后继续修改：** 中间结果已经删除。利用对话中已有的源视频、标题、时间点与选择重新建立临时任务；缺少必要信息时再询问，不假装还能读取旧 `job.json`。
- **未完成时更新排版规则：** 全局样式不会自动改变临时任务快照。用户要求采用新规则时，在临时工作区保存旧快照并更新 `job.style` 对应字段，保留标题和选帧；交付时旧快照一并删除。schema 2 的 `max_title_height_ratio_by_line_count` 按行数取高度，variant 的 `max_title_height_ratio: null` 表示用默认表，数值表示覆盖。旧 schema 1 的数值约束仍有效。
- **单独调整取景：** variant 的 `crop_anchor_override` 优先于公共锚点；保持选定原始帧，逐比例核对脸部和手势。
- **原视频改变或临时目录丢失：** 重新验证视频和抽帧，不跳过完整性检查。

## 完成判断

正式目录直接包含且仅包含五张图片，尺寸与画面已核对；原始媒体不变；旧工作目录及其他本次生成的中间副本已删除。最终回复给出该目录和总预览图，不把内部工作记录当交付物。
