# Changelog

## 2.2.0 — 2026-09-01

- 修复重复口播切点的三类真实失效：静音块不再跨 `0.55` 秒低声句首合并，只修补 `0.06` 秒以内的检测微裂缝；候选新增完整左桥接语、完整右句首和核心短语出现次数契约；普通气口补白后再次扣除重复范围，确保预检切点就是最终导出切点。
- 新增相邻长短语复读扫描，可直接拦截“要提高 Agent 的稳定性”这类连续重复；新增整片 PCM 粗剪预览命令，返修时先验证音频语义再决定是否重新编码 4K。
- 新增关键语句强调停顿计划：识别全片/章节结论、核心判断、重大转折与行动号召，默认把其前方可听停顿调整到当前约 `1.3` 倍，并在 cutlist 记录实际补回范围和审核状态。
- 增加低声句首、完整桥接语、完整重说前缀、短语计数、补白不得重新带回重复口播、强调停顿范围和整片音频预览回归测试。
- 补充第五课真实转写错题集，包括 `Snipaste`、`WorkBuddy`、`Chatbot`、`强直性脊柱炎`、`弹力带克数`、`道与术`、`复利资产`、`知行合一` 等术语与不可拆短语；阶段 B 明确要求重锚定后高密度失败必须回到 draft 重分配并重跑。

## 2.1.0 — 2026-08-27

- 新增运行耗时账本：粗剪交付时区分端到端总耗时、可测命令墙钟时间、判断与调度差额，并单独记录每次重试；4K 导出估时改用同机器、同规格和同编码器的最近实测倍率。
- 新增 `references/exception-playbook.md`，把门禁失败统一收口为“信号 → 最低成本处理 → 停止条件 → 沉淀位置”。异常优先通过草稿、短音频预览或局部帧条恢复，默认不触发第二次 4K 导出。
- 重复口播锚点新增区分度门禁：废弃版本与保留版本都会出现的通用短语不能作为唯一锚点；无法建立可靠锚点时增加上下文、组合锚点或保留候选。
- 审核 SRT 改为先集中完成术语、受保护短语、语义边界和长度检查，再进行第一次整片音频重锚定，减少 final lint 失败造成的分钟级重复处理；明确 `--skip-auto` 仍会重新运行音频重锚定。
- 回收本次课程素材的新错词和固定写法，包括 SRT、Python、Whisper、Markdown、YouTube Download、“自我纠错能力”“时间戳”等。
- 同步更新 `VERSION`、README 与 Claude 插件市场元数据到 2.1.0。

## 2.0.0 — 2026-08-14

- SKILL.md 从叙述式段落改写为编号门禁清单：每个步骤统一为「动作 → 门禁」结构，新增顶部「执行总览」表格固定步骤顺序（A0→A6、A0→B5），执行时不能凭感觉跳步或调换顺序。规则和阈值内容未删减，只是从大段夹叙夹议的段落搬进可勾选的门禁列表，降低长文里漏看某条约束的概率。
- 交付边界从一段说明文字升级为 A6/B5 的强制白名单收口门禁：收口时必须清点产出目录实际文件列表，逐一对照允许文件表，表外的任何文件——不论格式——一律不生成或删除。这是通用规则，不针对某一种具体文件类型，用于堵住"顺手多生成一份东西"这类没有被 skill 定义过的行为（例如阶段 B 曾经出现过的多余纯文本转写）。
- 正式确立 `fixed_terms.tsv` / `protected_phrases.txt` 为本 skill 的错题集：`calibration.md` Workflow 新增第 8 步"错题回收"，把此前"词表由使用者自行维护"的可选行为改成校准收尾前的强制闭环——本轮如果手动改过一个词表未覆盖的真实识别错误，必须写回词表并重跑 lint 确认新条目生效，不允许只在正文里改一次就结束。阶段 A 的 A4（复用同一套校准规则）同样受此约束。
- 修复 `marketplace.json` 版本号漂移：v1.8.0 发布时忘记同步更新，导致插件市场显示的版本落后 VERSION 文件一个版本；这次一并对齐并升级到 2.0.0。
- 步骤编号、脚本调用、命令参数、所有数值阈值（1.05s / 7.0s / -35dB / 0.5s / 0.05s 等）与 v1.8.0 保持完全一致，属于纯格式与收口规则重构，不改变粗剪与最终字幕的实际判定逻辑。

## 1.8.0 — 2026-08-14

- 修复真实事故：第三课最终字幕曾把未经术语校准的 whisper 原始转写直接当成交付版本（"Cloud"/"多包"等错误逐句照搬），而 `lint` 此前完全不检查 `fixed_terms.tsv` 的替换规则，跳过校准这一步不会被任何自动检查拦下。
- `lint_cues()` 新增残留别名检查（`find_unresolved_aliases`）：扫描输出文本中是否还残留 `fixed_terms.tsv` 里应被替换的别名（`always` 规则直接查，`contextual` 规则在上下文命中时才查），命中就报警告并提示"术语校准可能被跳过"。修复了大小写不敏感匹配把已经正确的规范写法（如 `AI`）误判为残留别名的问题。
- `lint_cues()` 新增悬挂连接符检查：字幕行尾如果是 `、`、`，`、`；` 等，会直接报警告，避免拆句后留下孤立的顿号。
- `apply_operations` 的 `split`/`repartition_pair`/`repartition_span` 现在会自动去除人工提供文本首尾的软分隔符（`、，,；;：:`），不再依赖人工检查。
- `calibration.md` 新增"Cue-boundary punctuation"规则：拆句时不要在行尾留下孤立顿号，要么去掉，要么把顿号后的词一并挪进这一句。
- `fixed_terms.tsv` 新增/修正别名：豆包（`都包`，且把"东方"独立为限定语境的 contextual 规则，避免误改真实的"东方"一词）、大模型（`大母型`）、新增预训练（`运训练`）、口播稿（`口博稿`/`口报稿`/`口播搞`）、粘贴（`粘键`，限定语境）。
- `protected_phrases.txt` 新增 `garbage in,garbage out`，避免这个英文习语被自动拆句拆断。

## 1.7.0 — 2026-08-14

- 长停顿画面审计从“开始/中间/结束”三帧升级为“停顿前/开始/中间/结束/停顿后”五帧，每行一个候选，可直接对比停顿前后的页面状态。
- 操作保护改为正向证据门禁：必须记录具体 `visual_evidence` 和 `protected_ranges_seconds`；静止页面、阅读/思考推测、光标轻微移动、选区取消或只有口播操作词不再足以保护停顿。
- `uncertain` 和无低声口播证据的 `retake_context` 不再自动完整保留，默认交给 `1.05` 秒普通气口规则。
- 操作只占长停顿的一部分时，仅恢复明确标记的最小操作窗口，其余静止区间继续压缩；报告新增 `partial_protection`。
- 用第三课第一部分实盘复核，将“这个要先搞清楚”与“明确了我们想要什么结果之后”之间的静止空白从宽松保护改判为普通口播停顿。
- 新增五帧取样、默认压缩不确定区间、正向证据必填和最小操作窗口恢复的回归测试。

## 1.6.0 — 2026-08-14

- 为实操型受保护空白增加 `7.0` 秒软上限：不超过 7 秒完整保留，超过时保留首尾各 3.5 秒并裁掉中间，同时保住“发起操作”和“结果出现”。
- `possible_quiet_speech: true` 的候选绕过 7 秒上限，继续完整保留，避免把低声口播误当空白删除。
- 停顿审计报告新增每个受保护候选的实际保留范围、保留时长、`capped_to_seconds` 和汇总字段 `capped_protected_count`；4K 导出门禁按实际保留范围验证。
- 组合门禁允许已经通过左右语义锚点的重复口播删除覆盖操作保护区间；未通过重复门禁的重叠删除仍会阻止 4K 导出。
- 4K 输出容器截止时间锁定到预计最后一帧，避免 AAC 尾包让音轨在片尾额外延长并触发同步门禁。
- 新增长操作空白均衡裁切、低声口播豁免、实际保留范围、重复口播优先级和容器截止时间等回归测试；完整测试增至 38 项。
- README 更新为当前两阶段工作流，并补充普通口播气口与实操型空白的不同规则。

## 1.5.0 — 2026-08-14

- 新增 `pause_visual_audit.py`：在实操演示粗剪前，把长静音按开始/中间/结束三帧和前后口播联合审计，区分操作、输入、页面切换、等待生成、普通口播停顿与疑似重说。
