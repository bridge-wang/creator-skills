# 从手剪参考学习节奏

用户的手剪结果定义其使用场景的标准。不要把某一次课程参数推广到短视频，也不要把一个用户的偏好当作通用视频标准。

## 测量口径

气口按两段可听口播之间的**声学停顿**测量，包含句间和短语间停顿。语法句号和 Whisper 字幕边界都不能可靠定义声学气口。

固定预处理为 16 kHz 单声道 PCM16；默认 `-35 dB`、最短 `0.12` 秒，只合并不超过 `0.06` 秒的检测微裂缝；排除片头片尾，记录样本数、均值、中位数、P90、最长值和每段源时间。

```bash
python3 scripts/pause_profile.py "<手剪参考>" --output "<临时目录>/reference-all.pauses.json"
```

参考同时含人物口播和软件演示时，结合转写和画面确认区间，另测人物口播部分。`--ranges` 接受 `[[start,end], ...]`，只纳入完整落在选定区间内的气口；不能只选择符合预期数字的停顿。

```bash
python3 scripts/pause_profile.py "<手剪参考>" --ranges "<临时目录>/talking-ranges.json" \
  --output "<临时目录>/reference-talking.pauses.json"
```

报告两组结果，按用户指定使用中位数。`references/pacing-profiles.json` 保存目标、测量口径、样本数和测量摘要哈希。媒体路径、完整转写和逐段结果仅存本地评测目录，不进入可分发规则。

## 执行这个标准

- 短视频把长于目标的普通气口缩到参考中位数附近；长视频与课程按用户指定的 0.7 秒执行。两种模式均保持较短气口原样，不统一补长所有停顿，不改变语速。
- 先合并重说剪辑后的时间轴，再计算气口。前一句尾白加保留句前卷，合起来才是观众听见的停顿。
- `autocut.py` 的两种模式都只从已确认静音里删中间部分，不用 auto-editor 的 4% 阈值直接删低声句首。
- 30 fps 时短视频目标约为 9～10 帧，长视频约为 21 帧；验收允许最多一帧加 10 ms 的量化误差。不要宣称帧级视频能精确到微秒。
- 两种模式都不自动增加强调留白；确需破例时记录用户要求和具体静音范围。
- 正向画面证据支持的实操时间仍保留最小窗口，按 [操作停顿审核](operation-pauses.md) 执行。

阈值附近有低声词、持续底噪或音乐时，先做局部核验并报告测量局限。不能不断调阈值直到得到想要的中位数。首次标定建议比较相邻阈值作为敏感性检查，但正式结果与执行必须使用同一口径。
